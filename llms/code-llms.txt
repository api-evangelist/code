# Code

> Code is an open, self-custodial payments protocol and mobile wallet built on the Solana blockchain. Its SDK lets any web developer embed a "Pay with Code" button and accept permissionless micropayments — as little as 5 cents per transaction plus a flat 1-cent blockchain fee — with no sign-up required and just a few lines of code. The API is defined as gRPC/Protobuf services; payments are created as idempotent intents and confirmed via JWT-signed webhooks or client-side events.

## API (gRPC / Protobuf)
- [code-protobuf-api](https://github.com/code-payments/code-protobuf-api): Protobuf API definitions
- [grpc/code-account-v1.proto](grpc/code-account-v1.proto): account service
- [grpc/code-currency-v1.proto](grpc/code-currency-v1.proto): currency/exchange service
- [grpc/code-messaging-v1.proto](grpc/code-messaging-v1.proto): messaging/stream service
- [grpc/code-transaction-v2.proto](grpc/code-transaction-v2.proto): transaction/intent/swap service
- [grpc/code-common-v1.proto](grpc/code-common-v1.proto): common models
- gRPC endpoint: https://api.codeinfra.net:443
